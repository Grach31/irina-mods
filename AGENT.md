# Как Claude готовит посты для канала Stambo.i

Канал Ирины (стилист, @stamboir) о моде: подборки вещей российских брендов, её находки, рубрики «История моды»
и «Новости модных домов».
Claude только **кладёт черновики** в папку `drafts/`. Всё остальное делает бот на GitHub (`.github/workflows/bot.yml`):
отправляет черновик Ирине с кнопками ✅ / ✏️ / ❌, публикует после её одобрения, складывает её просьбы в `data/requests.json`.
Ничего не публикуется без кнопки Ирины. Пост выходит в канал сразу после её ✅ (без расписания), поле `slot` всегда `null`.

## Что делать при каждом запуске

1. `git pull`. Посмотри `state/state.json` (статусы черновиков) и `data/requests.json`.
2. **Просьбы Ирины** — записи со `"status": "new"`: на каждую сделай черновик с `"request_id"` этой просьбы и `"slot": null`. Если к просьбе приложено фото (`photos`), посмотри его (Read).
3. **Правки** — черновики в `state.json` со `"status": "edit_requested"`: в поле `comment` написано, что поправить
   (иногда есть `comment_photos`). Сделай новую версию с новым id и `"revision_of": "<старый id>"`.
4. **Ежедневные посты** — если сейчас 8:00–11:00 МСК, проверь по `drafts/` каждую рубрику отдельно: чего из списка
   ниже с сегодняшней датой и `"daily": true` ещё нет, то и сделай (подборки ищи по `"type": "picks"`, новости — `"news"`,
   историю — `"history"`):
   - 2 подборки (`"type": "picks"`, `"daily": true`): **одна смешанная** (вещи 2–3 разных магазинов на одну тему)
     и **одна из одного магазина**.
   - Вторник и пятница: подборка одного магазина — «вещь мечты» (Askent или Ushatava, 1–2 вещи); смешанная остаётся.
   - Каждый день: дополнительно «Новости модных домов» (`"type": "news"`, `"daily": true`), см. ниже.
   - Воскресенье: дополнительно «История моды» (`"type": "history"`, `"daily": true`).
   Повторы: не бери вещи, которые уже были в `drafts/` за последние 14 дней.
5. Положи файлы в `drafts/` (с фото Commons — сначала через `"hold"`, см. «История моды»), `git add drafts && git commit && git pull --rebase && git push`. Пуш сам запустит бота.
   Если ничего делать не нужно — ничего не коммить.

## Материал для подборок

- `data/candidates.json` — новинки магазинов (обновляются в 7:00 МСК): `name, price, url, img, shop, kind`.
  `kind: daily` — Lime, Love Republic, 2MOOD; `kind: dream` — Askent, Ushatava.
- `data/sheets/<Магазин>.jpg` — сетка фото с номерами `#i` (номер = индекс в списке магазина). **Обязательно посмотри лист
  перед выбором** и бери только вещи с чистым студийным фото в одном стиле (без надписей, коллажей, обрезанной головы крупным планом).
- **Wildberries не использовать никогда.** Lamoda недоступна. Только магазины из списка выше.
- В подборке 2–4 вещи с общей темой: «тёплое на зиму», «трикотаж», «к джинсам» и т.п.
  - **Подборка одного магазина** — все вещи одного магазина.
  - **Смешанная подборка** — вещи 2–3 разных магазинов из списка выше (Lime, Love Republic, 2MOOD; Askent/Ushatava можно
    добавить одной вещью). Чтобы коллаж был цельным, по контактным листам бери фото с похожим фоном и кадром
    (все в рост на светлом фоне и т.п.). В списке вещей в тексте после цены указывай магазин:
    `<a href="URL">Бомбер с мехом</a> — 11 999 ₽ · Lime`. В id отрази смесь, например `2026-10-19-mix-warm`.

## Формат черновика `drafts/<id>.json`

id: `ГГГГ-ММ-ДД-<короткое-слово>`, например `2026-10-19-lime-knit`. Файл назови так же, как id.

```json
{
  "id": "2026-10-19-lime-knit",
  "type": "picks",
  "daily": true,
  "slot": null,
  "items": [{"name": "Свитер из шерсти", "price": 7999, "url": "https://...", "img": "https://...", "shop": "Lime"}],
  "text": "HTML-текст поста"
}
```

История моды:
```json
{
  "id": "2026-10-25-history",
  "type": "history",
  "daily": true,
  "slot": null,
  "hold": true,
  "card": {"kicker": "ИСТОРИЯ МОДЫ", "year": "1947", "note": "79 лет назад", "title": "New Look Кристиана Диора",
           "images": [{"commons": "Christian Dior New Look 1947.jpg", "grayscale": true, "fy": 0.2}],
           "credits": ""},
  "text": "HTML-текст поста",
  "sources": ["https://... откуда факт"]
}
```

## Текст поста (голос Ирины)

- Коротко: 2–5 строк своими словами + список вещей. **Вся подпись не длиннее 900 символов** (лимит Telegram 1024).
- Тон личный и живой, как подруге: «прям любовь», «цена вопроса», «очень нравится мне этот вайб». 1–2 эмодзи, не больше.
- Не выдумывай факты о самой Ирине (что она купила, носит, где была), если она сама этого не написала в просьбе.
- Вещи — ссылками, коротко: `<a href="URL">Бомбер с меховой отделкой</a> — 11 999 ₽`, каждая с новой строки.
- Telegram HTML: только `<b>`, `<i>`, `<a href="">`. Экранируй `&`, `<`, `>` в обычном тексте.
- В конце можно вопрос к подписчицам.

Пример:
```
Новинки Lime: тёплое на зиму, которое не выглядит как «просто пуховик» 🍂

Бомбер с мехом в хаки — фаворит подборки, с джинсами и грубыми ботинками будет огонь

<a href="https://limestore.com/ru_ru/product/37113-8015_543_312_xaki">Бомбер с меховой отделкой</a> — 11 999 ₽
<a href="https://limestore.com/ru_ru/product/36392-3505_479_201_temno_koricnevyi">Куртка на искусственном пуху</a> — 13 999 ₽
```

## Фото для карточек (история моды и новости)

В `card.images` у каждого фото один источник. Бот сам скачивает фото, берёт автора и лицензию и отбрасывает несвободные:
- `"commons": "Имя файла.jpg"` — Wikimedia Commons;
- `"met": 12345` — The Met Open Access, номер объекта из ссылки `metmuseum.org/art/collection/search/12345`
  (огромная коллекция костюма: Chanel, Dior, Balenciaga, Schiaparelli, Vionnet…);
- `"cleveland": "1995.123"` — Cleveland Museum of Art Open Access (id или инвентарный номер);
- `"openverse": "<uuid>"` — Openverse: свободные фото Smithsonian, Rijksmuseum, Europeana, Cooper Hewitt, Flickr и др.
  (id из ссылки `openverse.org/image/<uuid>`). Rijksmuseum, Smithsonian, Europeana, LACMA, Cooper Hewitt ищи на их
  сайтах и через Openverse; если фото там свободное (PD, CC0, CC BY, CC BY-SA), бери через `openverse`
  или через `"url"` с подписью в `card.credits`, только если сам проверил автора и лицензию;
- `"url": "https://..."` — прямая ссылка, подпись пишешь сам в `card.credits`.
Платные фотобанки (Getty, Shutterstock и т. п.) не использовать. Из облака эти сайты часто не открываются —
ищи через WebSearch/WebFetch, а картинку проверяй по превью бота (`"hold"`).

## История моды

- Повод: событие, которое случилось **в этот день** (дата публикации) в истории моды; если такого нет — событие этого месяца
  с круглой датой. **Факт и дату проверь по надёжному источнику** (WebSearch/WebFetch) и положи ссылки в `sources`. Не выдумывай.
- Фото только свободные: Commons и музейные источники выше. Из облака Commons не открывается, поэтому в `images` пиши **название файла**
  (`"commons": "Имя файла.jpg"`, без `File:`; найти можно через WebSearch — страницы `commons.wikimedia.org/wiki/File:...`).
  Бот сам берёт ссылку, автора и лицензию из API Commons, отбрасывает несвободные (всё, кроме PD, CC0, CC BY, CC BY-SA)
  и пишет подпись «Фото: автор, лицензия» на карточке. `card.credits` оставь пустым. Старый вариант `"url"` тоже работает,
  но только если ты сам проверил автора и лицензию.
- **Проверка картинки (обязательно для фото с Commons):** положи черновик с `"hold": true` и запушь. Бот (за 1–2 минуты)
  нарисует карточку в `drafts/img/<id>.jpg`, **не отправляя её Ирине**, и запишет итог в `state/state.json` → `held.<id>`
  (`preview_ready` или `error` с причиной). Делай `git pull` раз в ~30 секунд, пока там не появится этот id с новым `at`,
  затем посмотри картинку (Read). Подходит — убери `"hold"` из черновика, закоммить и запушь: бот отправит Ирине.
  Не подходит или `error` — поменяй файл в `commons` (черновик изменился — бот перерисует). После 3 неудач убери фото
  (`"images": []`) и отправь без него. Если бот не отвечает 10 минут — отправь без фото.
- На карточке 1–4 фото: 1 — во всю ширину, 2 — рядом, 3 — одно большое слева и два справа, 4 — сетка 2×2.
- **Фото к фактам.** Один факт — одно фото, поэтому в посте не больше 4 фактов, и фото идут в том же порядке, что факты.
  Лучше всего — **точное фото факта**: пишешь «Шанель придумала маленькое чёрное платье» — фото именно этого платья
  (или вещи этой модели/года), а не портрет Шанель; «Диор показал New Look» — снимок с того показа или костюм Bar.
  Проверяй по описанию файла (что изображено, год, дизайнер, коллекция). Если точного свободного фото нет,
  можно **общее по теме** (портрет дизайнера, дом моды, вещь той же эпохи), но текст не должен выдавать его за ту самую
  вещь. Сначала ищи точные фото и выбирай факты, к которым они нашлись; общие — только чтобы закрыть пробел.
- Текст: 3–4 коротких абзаца, без занудства, в конце вопрос.

## Новости модных домов

Раз в день (`"type": "news"`, `"daily": true`, `"slot": null`) — свежая новость мировых модных домов: новая коллекция или
показ, интересная вещь, коллаборация, тренд (Dior, Chanel, Gucci, Prada, Miu Miu, Saint Laurent, Louis Vuitton,
Bottega Veneta, Loewe, Balenciaga и т. п.).
- Новость не старше ~2 недель, не повторять дом/событие, которые уже были в `drafts/` за последние 7 дней.
- Факты (дата, место, дизайнер, детали вещей) — из надёжных источников: сайт самого дома, Vogue, WWD, Business of Fashion,
  Numéro, W и т. п.; ссылки в `sources`. Не выдумывай.
- Текст: 3–5 коротких абзацев голосом Ирины, вещь или образ описать красиво и конкретно (ткань, силуэт, цвет, с чем носить).
  **Без цен и без ссылок на магазины.** В конце можно вопрос к подписчицам. Подпись не длиннее 900 символов.
- Фото: 1–4 фото **с официального сайта дома** (страница показа/коллекции/новости) через `"url"`, в `card.credits` —
  «Фото: Dior» (название дома). С чужих сайтов, блогов, Getty и фотобанков не брать. Если на официальном сайте фото не
  достать — фото из свободных источников по теме (см. «Фото для карточек») или пост без новинки на фото не делать.
  Решение владельцев канала: идём на риск с фото брендов; если пост удалят по жалобе — перестаём и переходим на превью ссылки.
- На карточке в `year` — название дома крупно, если оно короткое (до ~8 букв: Dior, Gucci, Prada, Miu Miu, Loewe);
  длинное (Saint Laurent, Bottega Veneta) — в `title`, а в `year` сезон или год.
- Через `"hold"` так же, как «История моды»: посмотри превью и проверь, что на фото именно те образы, о которых текст.

```json
{
  "id": "2026-10-19-news-dior",
  "type": "news",
  "daily": true,
  "slot": null,
  "hold": true,
  "card": {"kicker": "НОВОСТИ МОДЫ", "year": "Dior", "note": "весна–лето 2027", "title": "Коротко о главном",
           "images": [{"url": "https://media.christiandior.com/...jpg", "fy": 0.15}],
           "credits": "Фото: Dior"},
  "text": "HTML-текст поста",
  "sources": ["https://www.dior.com/...", "https://..."]
}
```
