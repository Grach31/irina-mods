# My Space — отчёт по производительности

28 ноября 2026 года. Ветка `hotfix/myspace-performance`.

- База для сравнения — `8656e56face3fd2d072a60f84e35bf6060b2103f` (`main`).
- Коммит исправления и регрессионных тестов — `c9ec416a3429b566d5b54c41cd1ef48c123ec5cf`.
- Развёртывание через `main` оставлено на согласование владельца.

## Причины и исправления

| Подтверждённая причина | Что изменилось |
| --- | --- |
| После обмена токена экран загрузки ожидал `load()`. До восстановления сессии стартовал ещё один запрос каталога. | Главная доступна сразу после серверной проверки владельца. Каталог, формы и данные разделов загружаются по входу в соответствующий раздел. |
| На главной загружались каталоги Moda и приватные объекты. На карточку последовательно приходились список папки, манифест и четыре JPEG. | Приватный каталог читается только в доступных владельцу черновиках Moda. Списки, манифесты и фото использует одна очередь с максимумом три запроса одновременно. Фото загружаются при приближении к видимой области карточки или при показе слайда. |
| Обновление повторно скачивало все JPEG, пересоздавало Blob URL и целиком заменяло список. Смена экземпляра объекта закрывала открытую карточку. | Версия объекта берётся из метаданных Storage. JPEG проверяется по SHA-256 перед первым показом версии. Неизменённые проверенные байты переиспользуются в оперативной памяти. Список обновляется по ID. Карточка, выбранный слайд и позиция прокрутки сохраняются. |
| Параллельные вызовы при старте, возвращении на экран и свайпе мешали обновлениям. Ранний выход из запроса мог освободить блокировку до завершения смежного запроса. | Параллельные вызовы одного раздела разделяют текущий запрос. Свайп работает с активным разделом. Moda применяет общий каталог вместе с авторитетными статусами и сохраняет последнее подтверждённое состояние при сетевых ошибках. |
| Вход зависел от esm.sh. У некоторых запросов тайм-аут отсутствовал или заканчивался при получении заголовков. | Тот же Supabase SDK 2.105.0 поставляется с приложением. Запросы данных ограничены до окончания чтения ответа. Основной бюджет — 12 секунд, каталог приватных метаданных — 15 секунд. Предпросмотр и явная отправка получили отдельные сроки. |
| Скрытые разделы, повторная отрисовка и eager-фото добавляли работу при навигации. | Неизменённые данные разделов сохраняют существующую DOM-разметку. В списке «Находок из Китая» фото загружаются лениво. Синхронизация статусов публикации запускается в соответствующем разделе. Уведомления и настройки объединяют совпадающие запросы. |

Бюджет кэша проверенных JPEG — 32 МБ. При превышении лимита вытесняются неиспользуемые записи. Используемый в интерфейсе объект остаётся доступен до снятия отображения. Если его вытеснит лимит или пользователь откроет новую сессию, следующее обращение снова скачает JPEG и проверит SHA-256. Blob URL освобождаются при уходе изображения из видимой области, закрытии карточки и выходе. Приватные запросы используют `no-store`. Service Worker обслуживает push и переходы из уведомлений, без записи материалов в Cache Storage.

Проверка владельца через Supabase Auth и `session_exchange`, политики Storage, схема манифеста, контроль SHA-256 и публикация по явному подтверждению сохранены. При выходе локальное состояние и действующие запросы очищаются. Маркер начатого выхода предотвращает восстановление сессии после закрытия вкладки во время серверного выхода. Черновики, автоматизации, серверные функции и утверждённый макет сохранены. [Документация Supabase о сетевых настройках клиента](https://supabase.com/docs/reference/javascript/initializing) · [Жизненный цикл Blob URL](https://developer.mozilla.org/en-US/docs/Web/API/URL/revokeObjectURL_static)

## Фактические замеры

Измерения выполнены на Windows в Chromium 158.0.8127.88 и Playwright WebKit 27.2 с мобильной конфигурацией iPhone 13. В каждой ячейке медиана трёх запусков с каждой версией. Профиль 90 мс добавляет задержку к запросам данных. Профиль слабой сети добавляет 450 мс на запрос и ограничивает скорость ответов внешнего API и Storage до 256 КиБ/с. Браузеры запускали реальные копии приложения и SDK. API и приватные данные подставлялись на стенде. Фикстура содержит 63 общедоступных записи каталога и две приватные подборки с восемью JPEG. Для старого CDN стенд отдавал тот же SDK одним ответом.

Время главной считается от навигации до скрытия заставки после восстановления сессии. Повторное открытие — полная перезагрузка в том же контексте с сохранённой сессией. Замер трафика включает тела ответов, полученные от стенда. Заголовки и транспортное сжатие в объём трафика не входят. Перехват Playwright используется в обоих вариантах, поэтому цифры повторного открытия не показывают выигрыш от HTTP-кэша.

Итоговые прогоны прошли.

- Python — 29/29. В параллельном прогоне тест HTTP-ретраев с локальным тайм-аутом 0,2 с дал лишние повторы. Изолированный прогон полного набора прошёл.
- Node.js 24 — 74/74. Включены тесты публикации, контроля ревизий и блокировки повторной отправки, приложений уведомлений и Oura, жестов, кэша и SHA-256.
- DOM-интеграция — 3/3. Центр уведомлений, обновление разделов и редакционная публикация.
- Браузеры — 8/8 комбинаций движка и ширины в проверке интерфейса, отдельный Chromium-тест уведомлений и все 24 запуска сравнительного замера. В браузерных тестах не было отправок в Telegram.

Редакционные и публикационные тесты использовали фикстуры. Целостность реальных RLS-политик, вход владельца и доставка push в Safari и установленной PWA на физическом iPhone требуют проверки на устройстве перед выкладкой. По рабочему адресу проверена только публичная доступность HTML и каталога. Оба вернули HTTP 200. Закрытые данные владельца в замерах не использовались.

## Как воспроизвести

Из корня ветки, с Node.js 24 и установленным Chrome. Playwright на Windows использует локальный Chrome и сборку WebKit. Полный JS-набор читает исходники TypeScript с LF, как в CI Linux. Для этого на Windows подойдёт новый checkout с `core.autocrlf=false`.

```powershell
git worktree add --detach ../myspace-before 8656e56face3fd2d072a60f84e35bf6060b2103f
python scripts/build_miniapp_catalog.py
Push-Location ../myspace-before
python scripts/build_miniapp_catalog.py
Pop-Location
npm install --no-save --package-lock=false playwright@1.65.1 happy-dom@21.0.4
npx playwright install webkit
node tests/myspace-performance.cjs ../myspace-before
node --test tests/*.test.mjs
python -X utf8 -m unittest discover -s tests
```
