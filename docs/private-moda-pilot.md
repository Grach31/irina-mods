# Private Moda pilot

Uses the existing My Space Supabase Auth owner account and the new private bucket `myspace-moda-drafts`. No new project, no new authentication, no public photo upload, no Telegram action. Additive test branch only, no production deploy. Storage object names: drafts/<date-gcc-id>/<sha256>.jpg and manifest.json (manifest written last). JPEG bytes verified on upload and read. Import uses existing owner session; no service-role key in browser. Existing public drafts unchanged; private preview rows are explicitly non-publishable, isolated from moderation actions. The private import package is not stored in Git. This is for controlled personal review and does not establish reuse/publication rights. Tests use mock storage; live owner-authenticated import and iPhone validation remain required before merging. Existing single-writer rule for production publishing remains in force.
