# Находки из Китая

Источник карточек — публичная витрина Wildberries «Находки из Китая». Данные для приложения лежат в `miniapp/china-finds.json`. Редакция добавляет один плановый выпуск по московской дате, по два товара каждой из четырёх категорий. По отдельному запросу владельца можно добавить ещё один полный выпуск за ту же дату. Новые выпуски сверху. При исправлении сохранять прежний идентификатор товара. Выпуск с неполной квотой не заменяет последний полный выпуск.

| Поле | Формат |
| --- | --- |
| `schema_version` | Число `1` |
| `updated_at` | UTC в ISO 8601. Пустой каталог использует `null`. |
| `items` | Массив товара из всех выпусков, новые сверху |
| `id`, `wb_article` | Артикул строкой, идентификатор — `wb-<артикул>`. Дубли не допускаются. |
| `date` | Московская дата выпуска `YYYY-MM-DD` |
| `edition` | Необязательный целый номер выпуска за дату. Плановый выпуск использует `1` по умолчанию, дополнительный ручной выпуск — `2` и далее. Квота восемь товаров проверяется для каждой пары даты и номера. |
| `category` | `Одежда`, `Сумки`, `Обувь` или `Бижутерия`. Одежда и обувь женские. |
| `title` | Название товара, до 160 символов |
| `price` | Проверенная цена в рублях в виде числа больше нуля. Цена на WB может измениться. |
| `description`, `stylist` | Описание до 1200 символов, рекомендация стилиста до 800 |
| `url` | `https://www.wildberries.ru/catalog/<артикул>/detail.aspx` |
| `photos` | От 2 до 10 разных фотографий именно этого товара. Каждая запись — объект с `url` и `alt`. Допустимы прямые HTTPS-адреса с `basket-<номер>.wbbasket.ru`, `basket-<номер>.wb.ru` или `basket-<номер>.wbstatic.net`. Также поддерживаются оригиналы WebP с `<регион>-basket-cdn-<номер>.geobasket.ru`, путь `/vol…/part…/<артикул>/images/big/<номер>.webp`. Артикул в фото должен совпадать с артикулом товара. Для Telegram сервер преобразует WebP в JPEG. Фото должны открываться без редиректов и быть годны для ручной публикации. |
| `material`, `color`, `style` | Необязательные строки. Добавлять только проверенные сведения. |

Ссылка HTTPS передаёт открытие ОС. Приложение WB открывается при поддержке ссылки устройством и браузером. В остальных случаях открывается карточка сайта. В Telegram Mini App используется штатное открытие внешней ссылки.

Избранное хранится на устройстве. Публикация работает через существующий сервер редакционных публикаций: доступ модератора, предпросмотр фотографий и текста, подтверждение версии, сохранение результата и защита от дублей. Источник на опубликованных Pages и в `main` должен совпадать. Ветка редизайна проверяется с подменёнными ответами, а рабочий каталог остаётся пустым до появления проверенного выпуска.

Для будущего выпуска после отдельного разрешения нужно применить обновлённый SQL из `supabase/editorial/publications.sql`, затем развернуть функцию `myspace-publish`. Автоматизации для подготовки выпуска настраиваются отдельно.
